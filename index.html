Tính Cách Trợ Lý AI (AI Persona)

Lựa chọn phong cách và thái độ giao tiếp của NutriAI theo sở thích của bạn (hỗ trợ cả Gemini API và Chế độ Demo)

Prompt Hệ Thống (System Prompt)

Chỉ dẫn Gemini phân tích calo chuẩn và trả về khối JSON tự động cập nhật nhật ký sức khỏe

Cấu Trúc Gọi API Google Gemini Đang Dùng

Hệ thống kết nối trực tiếp theo định dạng chuẩn của Google:

curl "https://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent" \
  -H 'Content-Type: application/json' \
  -H 'X-goog-api-key: YOUR_API_KEY' \
  -X POST \
  -d '{
    "contents": [
      {
        "role": "user",
        "parts": [{ "text": "Explain how AI works in a few words" }]
      }
    ]
  }'
  • Lấy Key miễn phí: Truy cập Google AI Studio (aistudio.google.com) để tạo Gemini API Key.
  • Mô hình: gemini-flash-latest, gemini-1.5-flash hoặc gemini-2.0-flash (tốc độ nhanh và độ chính xác phân tích calo rất cao).
  • Chế độ Demo: Nếu chưa có key ngay, chỉ cần chọn "Chế Độ Demo" để thử nghiệm đầy đủ mọi tính năng.
